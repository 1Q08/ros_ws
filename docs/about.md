## 关于本站

**ROS 命令速查** 是一个面向机器人开发者的轻量级参考站点，收录了 ROS 1 与 ROS 2 中最常用的命令行指令。

### 维护方式

- 内容以 Markdown 编写，托管在 GitHub Pages。
- 欢迎提交 Issue 或 PR 补充你常用的命令。

### 技术栈

- Jekyll + minima 主题
- GitHub Pages 自动部署
